# Data

`data/raw/` holds two days of ClimSim low-resolution E3SM-MMF snapshots (`day1_*`, `day2_*`), each a set of 72 NetCDF files spaced 1200 s apart across 384 grid columns and 60 vertical levels. The directory is git-ignored because of size (~420 MB); it is not regenerated by any script in this repo.

To obtain it again:

- Source: [LEAP/ClimSim_low-res on Hugging Face](https://huggingface.co/datasets/LEAP/ClimSim_low-res)
- Expected layout:
  ```
  data/raw/
  ├── day1_input/   E3SM-MMF.mli.0001-02-01-*.nc   (72 files)
  ├── day1_output/  E3SM-MMF.mlo.0001-02-01-*.nc   (72 files)
  ├── day2_input/   E3SM-MMF.mli.0001-02-02-*.nc   (72 files)
  └── day2_output/  E3SM-MMF.mlo.0001-02-02-*.nc   (72 files)
  ```

Day 1 is used for training, day 2 for validation – see [`notebooks/01_rnn_climate_tendency_emulator.ipynb`](../notebooks/01_rnn_climate_tendency_emulator.ipynb).
